# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-09-05

### Added

- Telegram bot for applications, video submissions, withdrawals, referrals, and stats.
- Admin panel with role-based access (owner, financier, moderator, traffer, shnyr).
- PostgreSQL schema and migrations via Drizzle ORM.
- Configurable admin `basePath` for reverse-proxy deployments.
